Research Notes 01 / Web design

What makes a website feel professional?

A beginner-friendly research summary of common web design principles that help a site feel polished, clear and trustworthy. This is a qualitative learning summary, not a formal academic study.

Research question

How can a personal portfolio look polished while staying easy to use?

Working hypothesis: clear hierarchy, readable contrast, consistent components, responsive layouts and purposeful interactions contribute to a coherent experience.

Key observations

01

Visual hierarchy

Visitors often scan before reading in detail. Clear headings, concise descriptions and spacing help them understand what matters first.

02

Contrast and readability

A restrained accent colour can guide attention, but body text still needs comfortable contrast. WCAG asks for at least 4.5:1 for normal text. Try it in the Color Lab.

03

Consistency

Shared navigation, repeated card patterns and consistent buttons make a site easier to learn and reduce friction between pages.

04

Purposeful motion

Small effects confirm that an element is interactive. Motion should stay brief, and it should respect the prefers-reduced-motion setting.

05

Responsive behaviour

Layouts should adapt to phones, tablets and desktops. Cards stack on narrow screens, navigation collapses, and nothing needs horizontal scrolling.

06

Performance and honesty

Fast pages feel professional. This site has zero third-party libraries, and every demo clearly says when data is fictional or runs in your browser.

Applied in this portfolio

Design tokens in CSS variables, data-driven navigation, reusable cards, responsive breakpoints, skip link, keyboard-friendly dialogs and reduced-motion support.

Still to test

Screen-reader walkthroughs, real-device testing, Lighthouse scores, and feedback from actual visitors.

Research integrity note

This page summarises general design principles for learning. It does not claim original user research or measured results. For formal academic use, add verified sources and cite them directly.
